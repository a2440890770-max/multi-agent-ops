# D1 页面设计说明

版本 0.1，2026-10-27。配套：[接口契约](api-contract.md)、[逐项接口](api-reference.md)、[核心对象](domain-model.md)、[状态转换](state-transitions.md)。页面以“当前内容、需要处理的异常、下一步允许操作”为信息优先级；历史作为下层区块，不把执行、审批、发布、复盘混成一个状态。

## 路由、布局与实现边界

现有 React + Vite 上增加同源 History 路由，支持前进、后退、直接访问与刷新；不增加依赖。部署静态站需把非 `/api` 页面路由回退到 index.html；API 路径必须由后端处理。公共布局为侧栏导航、当前账号摘要、顶部位置与阶段、页面主体。手机上导航横向滚动，表格在容器内滚动，不产生整页横向溢出。未知路由展示返回入口。

| 页面           | 路由                               | 操作位置                                     | 接口及对象                                                        |
| -------------- | ---------------------------------- | -------------------------------------------- | ----------------------------------------------------------------- |
| 项目概览       | `/`                                | 运行环境卡片                                 | 原 `/api/health`、`/api/ready`、`/api/agent-health`，真实探测保留 |
| 登录与成员入口 | `/login`                           | 登录表单、当前身份及退出区                   | login/logout/getMe → Session/Member                               |
| 任务列表       | `/tasks`                           | 标题右上创建；表格筛选及查看                 | listTasks → Page<TaskSummary>                                     |
| 创建任务       | `/tasks/new`                       | 表单底部创建和返回                           | createTask → TaskDetail；固定团队账号                             |
| 任务详情       | `/tasks/:taskId`                   | 顶部复制/重执行/终止；右侧停止；正文底部保存 | getTask/taskHistory、各命令 → TaskDetail/History                  |
| 审核与发布区   | 详情 `#publication`                | 提交审核→批准→发布；交接/核实表单            | ReviewCycle/Approval/PublishOperation                             |

| 记忆管理       | `/memories`                        | 顶部类型/状态/用途筛选；右侧治理与同步       | list/get/edit/availability/delete/confirm/sync                    |
| 评测中心       | `/evaluations`                     | 实验摘要、运行已配置实验、盲评入口           | Experiment，list/run/getExperiment                                |

D1 已实现导航、公共布局、占位表单、示例筛选、详情场景与异常展示。全局显示“设计预览，示例数据，不保存或实际发布”；预览身份只改变布局，不用于 API 授权。真实业务接口返回 501；登录、实际任务创建、审核执行、发布、持久化及权限闭环留到后续。预览的保存/批准/停止只改变本页展示，刷新后重置；不能据此验收业务状态机。

## 页面布局草图

```text
公共侧栏             顶部：工作区 / 页面名                 阶段与预览提示
├ 项目概览           标题、当前账号/创建信息                 主操作
├ 任务工作台         ┌ 执行状态 ┬ 审批状态 ┬ 发布状态 ┬ 复盘状态 ┐
├ 记忆管理           异常/锁定说明（待核实、停止待确认、冲突优先）
├ 评测中心           内容与版本 | 审核与发布 | 复盘与证据（页内定位）
└ 管理设置           ┌ 主区：当前文案、保存、审核、发布/核实 ┐ ┌ 执行进度 ┐
                     │ 复盘：证据、假设、建议、不确定性     │ │ 版本历史 │
固定账号摘要         └────────────────────────────────────┘ │ 要求追踪 │
成员/权限入口                                               └──────────┘
```

列表优先显示待批准、执行中、待核实数量与任务表格，表格列包括标题、创建人、执行、审批、发布、更新时间及详情入口；任务编号作为次级信息。创建输入为标题（120）、主题目标（10000）、可选参考链接；业务校验失败保留表单。创建只保存任务，不自动开始执行。

详情主区约 2/3 宽，右侧执行、版本与追踪；窄屏上下排列。当前文案最突出，显示当前版本和来源；保存位于编辑器底部。审核与发布紧邻文案，显示版本绑定、审核结果、阻断、评分来源、批准事实及发布渠道。右侧执行进度含当前步骤、自动修改累计次数、错误及重试/停止入口。版本历史显示版本号、来源、时间和比较入口，历史记录只读，不把旧版直接设为当前版。

复盘放在同一详情页，先展示真实证据和观察，再展示假设、替代解释、建议验证及不确定性。候选保存入口附在具体建议旁，不自动确认或更新配置。记忆页采用左侧列表、右侧来源/版本/治理详情；删除记录不展示正文，清理状态独立于业务状态。评测先给摘要，盲评页面不显示模型、分组、配置身份或 Langfuse 轨迹；完成前不泄露答案。设置通过三个页签控制信息量，不向运营人员展示受限内容。

## 任务按钮与状态规则

通用：操作者须有相应权限且任务归属一致；可见操作若暂不可用，禁用并**展示原因文字**，不能只靠颜色或悬停提示；发布/回填/核实的收敛入口按对应状态出现。服务端 actions 决定展示建议，点击后依然重新校验。请求发送中禁用重复点击，但前端防点不能代替后端防重。

| 操作               | 出现位置/条件                         | 禁用原因与结果                                                                                 | 刷新数据                            |
| ------------------ | ------------------------------------- | ---------------------------------------------------------------------------------------------- | ----------------------------------- |
| 首次启动           | 无尝试的任务顶部                      | open、无工作/发布锁；接受后内容/审核/批准指针清空，进入待澄清/排队                             | 详情、列表、history                 |
| 澄清答复           | awaiting_clarification 顶部问题卡     | 必答问题缺失、版本变化、已请求取消禁用；追加答复                                               | 详情、问题与执行步骤                |
| 保存新版本         | 编辑器底部                            | open、无工作/发布锁、非空输入；同时提交 revision 和基版；批准尚未发布时可保存并失效批准        | 详情、版本、审核/批准资格、列表     |
| 提交审核           | 审核区                                | 仅已保存当前人工版，open、无锁；本地有未保存输入先保存；不创建新执行、不自动重写               | 周期 + 详情/列表                    |
| 人工裁决           | 审核区有主观分歧时                    | 输入理由、采纳/未采纳问题及证据；确定性阻断不可裁决；事实不足须补证或编辑重审                  | 决定、审核资格、详情                |
| 批准当前版本       | 当前审核通过/合法裁决后               | 无未解决阻断、版本稳定、无锁；绑定版本/摘要/账号；允许批准自己内容                             | 详情、批准和审计                    |
| 官方发布/人工交接  | 已批准版本发布区                      | 本地未保存、批准失效、账号权限不足、锁定或已发布禁用；官方能力不可用时说明原因；人工交接也占锁 | 稳定操作、详情、列表                |
| 停止本次执行       | 右侧执行区                            | 当前尝试待澄清/排队/执行中可请求；待确认时显示处理中并继续只读；确认 stoppedAt 后才编辑        | 详情/步骤，直到确认                 |
| 停止人工审核       | manual_submit queued/running 时审核区 | 同样需确认停止，不能直接释放槽                                                                 | 周期及详情                          |
| 终止任务           | 顶部次要操作                          | 无发布锁且未发布；输入原因；任务 terminated，有运行工作则同时取消但等确认；与停止执行区分      | 详情、批准、步骤、列表              |
| 重试/重新执行/重启 | 失败/结束/终止的任务顶部              | 无工作/发布锁，旧工作已隔离；terminated 须显式重启说明；新尝试从研究开始，旧历史保留           | 详情、attempts、版本、列表          |
| 回填人工发布       | awaiting_manual 专区                  | 冻结文案可复制；输入账号、平台标识/链接、实际摘要及证据；关闭界面不解锁；不匹配转待核实        | 操作、核实记录、详情/列表           |
| 核实发布           | verification_required 显著入口        | 三结论：匹配成功/明确未发布/仍未知；未发布须前次不会再生效的可靠证据，禁止无依据解锁           | 原操作及详情/列表                   |
| 明确失败后重试     | failed 专区                           | 仅有可靠未发布结论且批准仍有效；点击前显示原操作/前次发送/新渠道；待核实时绝不出现可用重试     | 同 operation 下 dispatch 增一、详情 |
| 复制为新任务       | 顶部，已发布时作为主操作              | 新任务标识/来源关联；可复制内容，不继承批准和发布；不自动执行                                  | 导航新任务/列表                     |
| 手动复盘/再次复盘  | 复盘区                                | 尝试结束、无工作/未决发布/并行复盘；有版本证据；新记录不覆盖旧结论                             | 复盘及历史                          |
| 保存候选           | 具体复盘建议旁                        | completed 才允许；同建议重复返回原候选；只保存候选                                             | 复盘候选关联、记忆列表              |

保存成功固定提示 **“新版本已保存，需要提交审核”**；清空旧审核资格，展示旧批准失效原因。审核通过再允许批准，批准完成再允许发布；点击批准不得自动弹出成功发布结果。三轮额度用当前完整尝试累计，手工编辑不清零；人工审核不消耗新的自动修改轮次。

执行中、排队中、待澄清、人工审核中，以及取消待确认均只读。停止请求只表示意图，页面继续展示停止中，不自行根据等待时长解锁。已发布原任务只读并突出“复制为新任务”。发布待核实在页面上方展示警示及核实入口，锁定正文、保存、审核/批准、重新执行和所有再次发送。

## 冲突交互

编辑器保留 `draftBody + baseContentVersionId + expectedRevision`，用户输入不随自动轮询覆盖。保存 409 时不改基版、不清空输入，不自动换 revision 重试。冲突区展示“我基于 V3/12；服务器 V4/13”、查看最新内容和并排比较入口。用户未保存输入在本地比较，不发送到只读版本比较接口。历史两个已保存版本通过 compareContent 获取 equal/insert/delete 片段。

比较后用户明确选择合并，重新读取最新并发号再保存；仍冲突继续提示。离开有未保存输入的页面，在业务接入阶段增加离开确认/会话级草稿保护；草稿不写入长期记忆。D1 已演示保留输入和并排比较，尚无持久草稿、合并器或业务写入。创建/登录/配置失败同样保留非敏感输入；不将密码持久化到浏览器存储。

## 全页面状态规范

| 页面      | 加载/空状态                                   | 失败/无权限                                                                     | 冲突/锁定/成功                                                                               |
| --------- | --------------------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| 登录      | 检查已有会话，提交中禁重复                    | 统一凭据错误，429 等待，禁用/过期提示；不泄露账号存在性                         | 成功加载 me 与权限再导航；退出撤销会话，未接入时不伪装登录                                   |
| 列表/创建 | 骨架、无任务带创建入口、筛选无结果允许重置    | 加载失败重试，401 登录；表单字段错误保留输入                                    | 创建成功导航详情；请求超时先按动作键查询，不重复创建                                         |
| 详情      | 整页 skeleton、404 返回列表、区块可独立无历史 | 加载失败保留最后确认状态，403 禁止全部写操作；Agent 错误显示 code/原因/人工重试 | 409 保留输入并比较；工作/发布锁显示所有者与可收敛入口；成功提示且更新引用                    |
| 记忆      | 列表骨架/无匹配，未选中提示                   | 召回/同步失败分开显示，清理失败保留原因范围；401 登录                           | 编辑/禁用/删除 expectedVersion 冲突保留输入；业务删除立即禁召回，同步继续显示 pending/failed |
| 评测/盲评 | 尚无实验、实验处理中、无待评样本表示完成      | 实验失败样本仍纳入摘要；提交失败保留评分，403 禁止提交                          | 配置/数据集冻结；盲评版本冲突不覆盖旧评分；结果不改变实际发布                                |
| 设置      | 当前版本加载，未授权摘要                      | operator 展示无权限；授权失败明确原因；不得显示秘密                             | expectedVersion 冲突保留表单并比较；成功显示新版本和变更人，重验受影响资格                   |

记忆编辑保留类型和来源；确认候选需明确人工确认、证据、理由与范围。删除需确认具体条目及“无回收站”；响应只表示业务 tombstone 已提交，清理成功前不显示全部清除。同步失败提供重试入口，已删除记忆无启用/恢复按钮。用途为正式创作时候选/禁用/删除不进入结果；用途/类型不相容要提示服务端 422，不在后台扩大用途。

## 数据刷新和异步行为

1. 进入业务页面先检查 me；加载业务资源和对应权限。D1 仅预览，不真的建立会话。
2. TaskDetail 响应一次携带当前对象、四维投影、工作锁和 actions，避免从多个过时响应拼装资格。历史与详情分开查询；区块可独立加载/失败。
3. 写入只以服务端响应为成功依据；无乐观批准、发布成功或停止确认。保存成功用响应当前版本更新缓冲区基版，保留旧版本历史。
4. 执行/审核/发布未决每 3 秒轮询，离开/页面隐藏暂停；失败保留最后确认状态，禁止因轮询失败解锁；每次更新都保护本地 draft。
5. 写入网络超时显示结果待查询，保留动作标识；发布未知保持锁并转核实，不套用通用重试。401 重新登录后不自动重放旧写入。

实际服务端副作用和上述轮询/认证/持久草稿待后续实现。D1 前端场景选择器属于评审工具，不作为业务产品最终入口；上线时移除或置于独立开发模式。

## D1 评审方法

`/tasks/task-demo` 的“预览场景”可看保存、审核、批准、执行只读、停止待确认、确定性阻断、冲突、人工交接、待核实、成功只读及明确失败。页面状态选择器可看 loading/empty/error/forbidden；顶部操作同步禁用。侧栏切换预览身份可核对设置权限布局。页面不得显示真实发布成功或已通过业务 AC。

三条必须共同走查的时序沿用状态表 S1—S3：修改使批准失效且并发保存拒绝；未知发布不重发、核实后收敛；候选不自动启用且删除立即禁召回、清理失败可见。D1 自动检查覆盖契约结构、占位无副作用与关键页面展示；数据库状态机、并发事务和真实外部发送仍需 M1—M5 专项测试。
