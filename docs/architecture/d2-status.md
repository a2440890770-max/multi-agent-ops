## 依赖与已知风险

- 精确依赖与间接依赖保存在根 package-lock.json，复现安装使用 npm ci。模型配置、搜索权限和 Mem0 运行配置分别见下方说明。
- npm audit 实际报告 3 项 high，来自 Mem0 内部 Zod 3 及其依赖链。自动修复建议会降级 Mem0 至 1.x，本次未执行；生产使用前需要处理上游兼容修复与受影响输入路径。
- SDK、服务商模型别名、搜索供应商和本机嵌入模型可能变化；改变版本、模型或摘要后需重新进行对应真实验证。
- CI 只运行不付费的检查与测试，不启动 Ollama、不配置模型 Key、不自动运行真实外部调用。

## 复现入口

```sh
npm ci
npm run check
npm run model:verify
npm run search:verify
npm run search:verify -- --deny-search
ollama pull nomic-embed-text
npm run memory:setup
npm run memory:verify -- --recreate-db
```

模型和搜索真实命令需本地 DEEPSEEK_API_KEY 并产生相应服务费用；搜索负向命令预期退出 1，错误维度也预期退出 1。真实命令报告默认写入 Git 忽略的 artifacts/ 子目录，已有报告不会覆盖。普通启动保持原有健康检查行为，不自动执行任务、发布或记忆提取。
