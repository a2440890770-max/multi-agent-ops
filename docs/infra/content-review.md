# 微博文案与审核闭环

在已有任务、会话、团队权限、幂等请求和数据库执行检查点上实现。应用新增迁移 `0005_content_review_workflow.sql` 、`0006_workflow_integrity.sql` 和 `0007_workflow_namespace.sql` 后使用；已有人工审核分支按[兼容升级](database-recovery.md)处理。

## 执行与额度

- `TASK_EXECUTOR_MODE=mock`：不调用外部模型，适合验收。新增 `review_failure`（连续不通过）、`factual_failure`（99 分但证据不足）模拟情形。
- `TASK_EXECUTOR_MODE=agent`：后端调用本地 Agent `/workflow`，由现有 DeepSeek / Claude Agent SDK 进行结构化生成和独立 Review。需配置 `DEEPSEEK_API_KEY`，实际执行会产生模型费用。生产允许显式 agent；默认仍 disabled。
- 初稿的 `revisionRound=0`。每次不通过的 Review 与下一轮额度预留在同一事务提交，最多预留三轮。持续不通过时只有 `[0,1,2,3]` 四个版本和四次对应审核，随后 `manual_required`，不再调度。
- 每个模型步骤最多三次技术调用，网络错误、格式错误和结构校验失败复用原步骤、尝试和修改轮次。重启进程不清零额度。技术失败耗尽后停止，需人工处理。
- 用户显式“调整要求并新执行”调用 `attempt-retries`，新增 attemptNo、冻结新要求并保留旧尝试及额度；这是新的完整执行。终止任务需要 `restartTerminated=true`。

## 版本与审核

`content-versions` 保存每版原文、父版本、来源尝试、手动/自动来源和修改轮次。`reviews` 保存目标版本、检查项、0—100 评分及来源、事实判定、事实引文、阻断问题和建议。历史接口完整返回 `contents/reviews/decisions`，审计仍单独分页。列表/单项读取接口支持同团队查询。

Review JSON 必须通过共享 Zod 结构校验。服务端再次执行非空、2000 Unicode 字符上限和控制字符检查，并核对引用 ID 及原文片段。`factualEvidenceSufficient=false`、声称有事实但没有引用、未知来源、无法核对的引文及 factual 阻断，均不能由高分或 `outcome=pass` 放行。语义支持和事实覆盖由独立 Review 判断；这不等于对事实进行了外部独立验证。

当前资料 URL/标题只作为参考来源展示，没有自动抓取或搜索。提供给模型的事实原文是任务要求及已保存澄清答复；需要外部来源才能支持的断言必须阻断、删改或由用户补充要求后重新执行。模拟评分明确显示为“规则/模拟”。

## 人工处理

详情页展示所有版本、每次 Review 和人工裁决。运行中先“人工接管（停止当前工作）”，再编辑。停止在事务中增加工作代次，所有迟到调用必须通过工作代次、目标版本、周期和租约令牌检查才能落库；旧自动结果无法覆盖人工版。

`POST content-versions` 同时比较任务 revision 与基础版本 ID。保存新人工版会运行基础校验并清空当前审核资格，正文不会被自动修改。格式错误可保存，但不能通过审核。人工明确提交 `POST reviews` 只审核该版，不触发自动修改，不重置原尝试的三轮额度；运行中的人工审核也占工作槽，可停止后继续编辑。

人工裁决只适用于最新、当前版本的已完成审核中的 subjective 问题。接受与保留的 ID 必须互斥且完整覆盖；必须填写原因。仍有保留意见则继续待人工处理。factual 和 deterministic 阻断必须修复并重审。裁决追加独立记录，不修改旧 Review 或分数。终止会隔离所有在途结果并保留历史。

文案、裁决和终态审核由数据库触发器防止修改或删除；同一尝试修改次数不能减少。所有写操作沿用 Session、Origin、CSRF、当前成员、团队与 revision 校验；幂等响应和审计同事务保存。

本次没有实现微博实际发布或批准接口，审核通过或人工裁决通过只表示当前文案可继续人工处理。

## 验证

`npm run check` 检查契约、格式、静态检查、类型、单元测试与构建。`TASK_TEST_DATABASE_URL` 指向随机命名 `tasks_test_<12位十六进制>` 独立测试库后运行 `npm run tasks:test`。新增验收涵盖四版四审停止、99 分事实阻断、基础校验、人工重审、主观裁决、显式新执行、同轮技术重试、在途生成/审核接管隔离以及历史不可变。
